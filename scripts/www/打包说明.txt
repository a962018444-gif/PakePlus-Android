市场情绪跟踪系统（安卓 WebView 打包版）—— 打包说明
========================================================

一、本文件夹内容
  1. index.html ............ 主程序。SheetJS 与 ECharts 两个库已完整内嵌，
                             纯离线、零外部网络依赖，file:// 下可直接运行。
  2. lib\xlsx.full.min.js .. SheetJS 库文件（随包备查，index.html 不依赖它）
  3. lib\echarts.min.js .... ECharts 库文件（随包备查，index.html 不依赖它）
  4. 打包说明.txt .......... 本文件

  重要：打包时只需选中「本文件夹」作为网页根目录，确认根目录下能看到 index.html。
        lib 文件夹仅作留档参考，可一并打包，也可删除，不影响程序运行。
        请勿改用电脑版那个依赖 CDN 的 html，离线会白屏。


二、安卓修改大师打包步骤（请按顺序操作）
  1. 打开安卓修改大师 → 选择「打包 APK / 网页打包」功能。
  2. 打包目标：选「安卓」。
  3. 来源：选「本地网页目录」，点击浏览，定位并选中本文件夹：
       C:\Users\Administrator\Desktop\市场情绪跟踪系统_安卓版\
     确认根目录下有 index.html（这是打包入口，不能只选 lib 子文件夹）。
  4. 内核：选「Android WebView」。
     不要选 X5 或其他内核；程序已针对标准 WebView 验证，库全部内联，
     不受 X5 差异与 file:// 跨域限制影响。
  5. 页面风格：选「普通」。
     不要选会裁剪视口或遮挡状态栏的风格，以免挤占输入区域。
  6. 屏幕方向：选「自动跟随 / 不锁定」，由重力感应决定横竖屏。
     程序本身已同时适配：竖屏两图上下排列可滚动，横屏两图左右并排；
     旋转屏幕后监听 orientationchange/resize 自动调用 echarts.resize() 重排，不会变形。
     如果你希望固定横屏或竖屏，也可自行锁定，程序两种方向都能正常显示。
  7. 返回键行为：选「先返回历史网页，再退出」，并打开「退出确认」。
  8. 权限（关键，务必开启）：
     · 文件选择 / 存储读取权限：必须开启。
       否则点「选择文件」没有任何反应，无法导入 xlsx。
     · 下载 / 存储写入权限：必须开启。
       否则导出 xlsx 后在下载目录找不到文件。
     · 网络权限：可以不申请（本应用完全离线运行，不发起任何网络请求）。
  9. 应用信息填写建议：
     · 应用名：市场情绪跟踪系统
     · 包名：com.sentiment.tracker
       （若提示包名已存在，可改为 com.sentiment.tracker.v2 等）
     · 版本号：1.0（versionCode = 1）
     · 图标：任选一张 512x512 PNG；没有专门图标可用默认图标。
     · 签名：首次打包可直接使用默认签名 / 自动生成签名。
       请务必自行保存好签名文件：后续升级版本必须使用同一个签名，
       否则手机会拒绝覆盖安装（提示"应用未安装"）。
  10. 点击生成。生成后先「保存 APK」，再「保存源码 ZIP」留档备份。


三、安装到手机后的验证清单（建议逐条做一遍）
  1. 手机开启飞行模式，安装 APK 并打开。
     应直接看到引导页「请先导入 xlsx 数据文件」——说明内嵌库生效、纯离线可用。
  2. 点引导页的文件选择按钮，从手机存储中选「每日sx情况统计.xlsx」。
     应自动解析并进入主界面，提示"已导入 N 行，日期范围 ..."。
  3. 切到「录入」页，填一个日期和若干数量，点「保存 / 写入」：
     应提示"已新增"或"已覆盖"，总记录数相应变化。
     再故意填一个 3.5，应被拒绝并提示"必须是非负整数"——严格校验生效。
  4. 把应用完全关掉（从最近任务里划掉），重新打开。
     应直接进入主界面并显示刚才的数据，无需重新导入——localStorage 持久化生效。
  5. 旋转屏幕：竖屏 → 横屏 → 竖屏，切到「走势图」页查看：
     横屏两图并排、竖屏两图上下堆叠，图形不变形、不溢出。
  6. 切到「明细」页，点底部「导出 xlsx 到手机下载目录」，
     到手机「下载 / Download」目录查看是否有：
       每日sx情况统计_导出.xlsx
     打开确认含三张表：每日sx情况统计 / 恐惧贪婪 / 累加恐惧。
  7. 切到「设置」页，改一个权重或窗口 N，点「应用设置」；
     回明细页确认恐惧/贪婪/累加值已随之变化；再关掉重开，确认设置也还在。


四、常见问题
  Q1：点「选择文件」没任何反应，或选完文件没导入？
      A：安卓修改大师打包时未开启「文件选择 / 存储读取」权限，或内核选错了。
         重新打包并开启该权限、内核选 Android WebView；
         同时确认打包的是本文件夹的 index.html。

  Q2：提示"未解析到有效数据行"？
      A：请确认选的是原数据文件「每日sx情况统计.xlsx」，
         且表①的 B 列为日期、数据从第 3 行开始。
         程序会跳过日期格式不合法的行，只保留 yyyy.m.d 形式的日期行。

  Q3：导出后下载目录里没有文件？
      A：检查是否已开启「下载 / 存储写入」权限；MIUI 还需在系统设置中
         给本应用授予「文件与媒体」或「存储」权限。
         程序在导出后会给出兜底提示："若未开始下载，请在浏览器 / 系统设置中允许本应用下载文件"。

  Q4：图表不显示 / 一片空白？
      A：确认打包入口是本文件夹的 index.html（库已内嵌），
         而不是电脑版那个依赖 CDN 的 html（离线必然失败）。
         另外确认内核选的是 Android WebView。

  Q5：关闭重开后数据没了？
      A：检查是否在「设置」页误点了「清空数据 / 回到导入引导」。
         另外，卸载应用会连带清除 localStorage，请定期用「导出 xlsx」备份。

  Q6：录入时小数被拒绝？
      A：这是刻意设计。录入数量必须是非负整数，空单元格按 0，
         不静默四舍五入。只有历史 Excel 导入路径按原表的取整语义宽松处理。

  Q7：横屏时图表挤在一起？
      A：程序已用 @media (orientation: landscape) 适配，并监听旋转事件重排。
         若打包壳强制锁定了某个不支持的方向，可改为「自动跟随 / 不锁定」。


五、技术说明（供二次开发参考）
  · 计算口径与电脑版完全一致（纯函数逐行等价）：
      总数 O   = SUM(C:N)
      下跌 P   = SUM(C:G)
      上涨 R   = SUM(I:M)
      恐惧 AF  = ((Q/O)*0.05 + ((C+D+E)/O)*0.8 + (P/O)*0.15)*100
      贪婪 AG  = ((S/O)*0.01 + ((K+L+M)/O)*0.8 + (R/O)*0.19)*100
      累加恐AI = 最近 N 日恐惧滚动求和（默认 N=20，不足 N 天按已有天数）
      除零保护：O=0 时占比与指数全部为 0；空单元格按 0。
  · 存储：localStorage key = sentiment_data_v1，
    保存完整 records + 当前设置（权重/窗口）+ 当前日期区间；
    容量溢出时 try/catch 捕获并弹明确提示，不静默丢数据。
  · 导出：XLSX.write(wb, {bookType:'xlsx', type:'array'}) → Blob →
    <a download="每日sx情况统计_导出.xlsx">，无需用户选路径，统一进 Download 目录。
  · 顶部四标签：录入 / 走势图 / 明细 / 设置，纯 CSS + JS 切换，无外部 UI 库。
  · 触摸友好：按钮与输入框 min-height ≥ 42px。
  · 配色：涨红跌绿（中国习惯）—— P/Q 绿、R/S 红；
    图1 恐惧蓝 #5B9BD5、贪婪橙 #ED7D31；图2 累加恐蓝色单折线。
  · 代码使用 ES5 兼容写法（var / function），避免老 WebView 语法报错。
